3. Remote Desktop Installation and Connection ​

3.1 VNC Installation and Connection ​

3.1.1 Getting Ready ​

A laptop computer is required. If you are using a desktop computer, please prepare your own wireless network card. The demonstration video is in the current section folder.

3.1.2 VNC Installation ​

If you want to execute the game program through the computer and attempt to view the program code later for modification, you need to complete the study of this section and install the VNC software.

VNC is a graphics remote control software. With VNC, we can control the Raspberry Pi directly from your computer through the hotspot created by Raspberry Pi. The installation steps are as follows:

  1. Double-click the “VNC-Viewer-6.17.731-Windows” program in this directory. Select “English” as the installed language, then click “OK” button.
  1. Click “Next” button.
  1. Then click “I accept terms in the License Agreement” in the prompt box, and click “Next” button.
  1. When you navigate to the next screen, simply click the “Install” button.
  1. After waiting for a moment, the installation completion prompt will appear. Then click “Finish” button to install VNC.
  1. After installation, click icon to open VNC.

3.1.3 Turn on Robot ​

Following what you've learned earlier, push the switch on the Raspberry Pi expansion board after connecting the adapter. After a brief moment, the LED1 on the expansion board will change from steady to flashing every 2 seconds. At the same time, all servos on the hand will assume a gripping posture, indicating a successful startup.

3.1.4 Device Connection ​

  1. After turning on the robot, it will generate a hotspot starting with “HW”. We can open the computer's Wi-Fi and search for it as pictured:
  1. In the opened VNC Viewer, enter the default IP address of the Raspberry Pi: 192.168.149.1, then press Enter. If prompted that it's not a secure connection, click "Continue."

2-2 IP Input method

  1. A prompt will appear asking you to enter a username and password:

  • For the 4B version, the username is pi and the password is raspberry.

  • For the Pi 5 version, the username is pi and the password is raspberrypi.

    Check the "Remember Password" box, then click OK. After this, you should be able to see the Raspberry Pi desktop.

  1. On the desktop, there is a warning dialog box (a feature of the Raspberry Pi itself). Simply click "OK" to close it. If it's a black screen with only a mouse cursor, you may try restarting the Raspberry Pi.

The detailed startup steps for each experimental game can be found in the subsequent chapters of the courses.
