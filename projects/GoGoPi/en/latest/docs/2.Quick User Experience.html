2. Quick User Experience ​

2.1 App Installation and Connection ​

The following instructions use TurboPi as an example and apply to other Hiwonder Raspberry Pi series products, including GoGoPi, as well.

In this section, you will learn how to use install the “WonderPi” app and connect to the app. The installation method is as follows.

NOTE

Notes:

1. Make sure all app permissions are turned on in settings, otherwise app functions will be limited!

2. Turn on Location and WiFi before operation.

2.1.1 App Installation ​

Directly scan the QR code below to download and install app.

2.1.2 App Connection ​

In this section, you will learn how to use the “WonderPi” app to control GoGoPi. This section demonstrates how to connect GoGoPi to the app.

NOTE

Notes:

1. Please turn GoGoPi on before connecting.

2. Make sure all app permissions are turned on in settings, otherwise app functions will be limited!

3. Turn on Location and WiFi before operation.

2.1.2.1 Turn on Robot ​

Start the robot. The switch is on the Raspberry Pi expansion board. For detailed startup instructions, please refer to “1. Getting Ready/1.3 First Power-On”.

2.1.2.2 Connect Robot to App ​

After GoGoPi boots up successfully, it enters AP direct connection mode, and generates a WiFi starting with “HW”. Join this WiFi, and then you can experience robot games.

There are two connection modes, namely direct connection mode and LAN mode. App functions are the same under these two modes.

Introduction to Connection Mode

There are two connection modes.

1 AP direct connection mode: RaspberryPi generates a WiFi which can be connected by phones. But this WiFi has no internet access.

2 STA LAN mode: Raspberry Pi actively connects to specific WiFi. In this mode, you can access internet.

Direct Connection Mode (MUST-READ)

NOTE

After GoGoPi boots up successfully, it enters AP direct connection mode, and generates a WiFi starting with “HW”.

  1. Open “WonderPi”. Select “Standard -> TurboPi” in sequence.
  1. Tap “+” in bottom right corner, and then select Direct Connection Mode.
  1. Tap “Go to connect device hotspot”. Join WiFi starting with “HW”. The password is “hiwonder”.
  1. Return back to app after connection.

NOTE

For iOS user, please don’t return to app until WiFi icon appears on status bar, otherwise robot cannot be searched. If robot cannot be searched by app, tap to refresh.

  1. App automatically connects to robot. When robot icon below occurs, connection completes.

NOTE

If you are informed of “No Internet. Whether to keep connection”, just select “keep connected”.

  1. Tap robot icon to enter mode selection interface.

For detailed introduction to robot games, please refer to the file in “2. Quick User Experience/2.2 APP Control”.

LAN Connection Mode

  1. Disconnect the WiFi generated by GoGoPi. Connect your phone to a WiFi.

Take “Hiwonder” as example.

  1. After connection, open “WonderPi”. Select “Standard -> GoGoPi” in sequence.
  1. Tap “+” in bottom right corner, and then select LAN Mode.
  1. Input the password of the WiFi your phone joins. Ensure the password you input is correct, otherwise app fails to connect to robot. Tap “OK”.
  1. Tap “Go to connect device hotspot”.
  1. Join the WiFi starting with “HW”. The password is “hiwonder”. After connection, return back to app.
  1. App automatically configures network.
  1. After a while, robot icon below occurs, and LED on expansion board keeps on.
  1. Long press the robot icon to check GoGoPi’s IP and ID.
  1. Tap robot icon to enter mode selection interface.

For detailed introduction to robot games, please refer to the file in “2. Quick User Experience/2.2 APP Control”.

2.2 APP Control ​

2.2.1 Getting Ready ​

Follow the tutorials in “2. Quick User Experience/2.1 App Installation and Connection” to install the app and connect to the GoGoPi.

2.2.2 Start Games ​

  1. Click GoGoPi icon to enter interface.
  1. All games are shown in interface. After selecting one of the games, the image will prompt “switch game successfully”. For example, click the game such as “Body Remote Control” to enter the corresponding interface.
  1. In this game interface, the left button are used to control rotation angle of pan-tilt of GoGoPi. The middle interface displays the real-time image. The right button are used to control the movement of GoGoPi.
  1. Touch the mobile phone screen with your finger, and the interface as follow will be displayed. Click button to take real-time photo. The photo can be checked when return to main interface and then click “Photo” to view.

If you want to learn the working principle of each game function, please come to folder “4. AI Vision Projects”.

2.3 Adjust Color Threshold ​

Different light source will have different influence on the colors, which will result in recognition discrepancy. To tackle this problem, you can adjust color threshold via “WonderPi” app.

2.3.1 Preparation ​

Start the robot. Open “WonderPi” app, and connect it to the robot. For how to connect robot to app, operate referring to “2.1 App Installation and Connection”.

2.3.2 Interface Layout ​

Tap in upper right corner to enter color threshold adjustment interface.

The table below list function of specific icon.

IconFunction

Processed camera returned image.

Target object is white, and other area is black.

Raw camera returned image.

Select the color to be adjusted.

Adjust L component of camera returned image. “L_min” is lower limit and “L_max” is upper limit.

Adjust A component of camera returned image. “a_min” is lower limit and “a_max” is upper limit.

Adjust B component of camera returned image. “b_min” is lower limit and “b_max” is upper limit.

Get instruction to check how to adjust color threshold.

Save the adjusted color threshold.

Return back to mode selection interface.

Hide navigation bar.

Display Hiwonder info.

2.3.3 Adjust Color Threshold ​

  1. Select color to be adjusted. Take red as example.
  1. Put red object within camera recognition zone. Set L_min, a_min and b_min to 0, and L_max, a_max and b_max to 255.
  1. Tap “Instruction” icon to check how to adjust color threshold.

NOTE

If you need to close Instruction window, select “OK”.

  1. Red approaches “+a” zone, so you need to adjust A component.
  1. Keep “a_max” value the same, and then increase “a_min” value till red object turns white and other area is black.
  1. Adjust “L” and “B” values. If it belongs to light red, increase L_min. Otherwise, decrease L_max. If it belongs to warm tone, increase B_min. Otherwise, decrease B_max.
  1. Remember to save the value after adjustment.
